Drop your café photos here. The site references these filenames (any missing
image gracefully falls back through the layered chain:
   local file → curated Unsplash image → warm gradient).

  hero.jpg          — the centerpiece photo of your café (the one with the olive tree)
  olive-tree.jpg    — vertical detail of the olive tree (used in the Story block)
  about.jpg         — vertical hero for the About page
  cta.jpg           — wide atmospheric shot for the closing CTA
  admin.jpg         — vertical photo for the admin login

  tile-tree.jpg     — Atmosphere · the tree
  tile-light.jpg    — Atmosphere · rattan pendants / soft warm light
  tile-concrete.jpg — Atmosphere · concrete & cream textures
  tile-coffee.jpg   — Atmosphere · brewing / coffee close-up

Recommended specs: ~1600px on the longest edge, JPEG, ~80% quality, sRGB.
The hero photo gets a subtle CSS color-grade pass (warmth, contrast, vignette)
applied automatically — feed it a clean, lightly-graded photo and let the
site finish the look.
